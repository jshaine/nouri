# Nouri

An offline-first, mobile-first macro tracker PWA. All data stays on your device.

## Development

```bash
npm install
npm run dev        # http://localhost:5173 (component gallery at /#gallery)
npm run ci         # lint, format, typecheck, tests with coverage, build, e2e
```

## Food data

The bundled food database (`public/foods.json`) is generated by
`npm run build:foods` from USDA FoodData Central CSVs (and FNRI data, if you
have it with permission). See [data/raw/usda/README.md](data/raw/usda/README.md)
for the downloads.
