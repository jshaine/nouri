# Nouri

An offline-first, mobile-first macro tracker PWA. All data stays on your device.

- **Today**: a Daily Facts label, meals, quick add from search, recents and
  favorites, edit and delete with undo, optional exercise calories.
- **Foods**: 8,000+ USDA foods and 1,000+ Philippine packaged products, searched offline, portions in grams, ounces or
  servings, and your own foods (with a reference search to copy facts from).
- **Goals**: onboarding suggests calories and macros from age, height, weight
  and activity; edit them any time in Settings.
- **History** by week, **weight** log, **profile**, and **backup and restore**
  to a file.

## Development

```bash
npm install
npm run dev        # http://localhost:5173 (component gallery at /#gallery)
npm run ci         # lint, format, typecheck, tests with coverage, build, e2e
```

## Food data

The bundled food database is generated by `npm run build:foods`:

- `public/foods.json`: USDA FoodData Central (public domain). See
  [data/raw/usda/README.md](data/raw/usda/README.md) for the downloads.
- `public/foods-ph.json`: Philippine packaged products (Gardenia, San Marino
  and more) from [Open Food Facts](https://world.openfoodfacts.org), filtered
  for complete, consistent label facts. Refresh with `npm run fetch:off`. This
  file is © Open Food Facts contributors, under the
  [ODbL](https://opendatacommons.org/licenses/odbl/1-0/); see
  [data/raw/off/README.md](data/raw/off/README.md).
- `public/foods-fnri.json`: FNRI data, only if you have it with permission
  (never committed).
